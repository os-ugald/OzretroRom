## Installation order

1. Review these generated files in Forge.
2. Apply the same content to the repository through a documentation-only Claude Code Gate.
3. Validate `git diff --check` and that no functional code changed.
4. Commit/push governance only after review.
5. Replace ChatGPT Project Sources with the three canonical Project Source files.
6. Paste `PROJECT_INSTRUCTIONS_V4.txt` into Project advanced instructions.
7. Create Ideas Lab and Platform Lab.
8. Update existing UI/UX, Windows and Helpdesk chats with their current V4 charters
   if needed.
9. `DOWNLOAD-UX-START-01` is cancelled by Product Owner and is not a GBA blocker.

## Non-goals

Governance V4 does not:
- enable GBA acquisition;
- change launch validation;
- change Source Index identity;
- modify Android code;
- certify any AI role externally;
- activate Windows/TV/Cloud features;
- close the GBA repair Gate.

## Certification/role rule

The role competency matrix gives specialists the ability to research and align
with current official certification domains/standards.

It does **not** authorize fake claims such as:
- “PMP-certified AI”
- “TOGAF-certified AI architect”
- “OWASP-certified app”

Use:
- STANDARD_ALIGNED
- OZ_QUALIFIED

for AI role competence, backed by sources and evidence.
