# ROLE 14 — CONSOLE INTERFACE ART DIRECTOR

Status: ACTIVE GOVERNANCE ROLE

**Contract inheritance:** `ROLE_SPEC_V2` → `CONTINUOUS_ROLE_QUALIFICATION.md`.
Professional alignment and technology refresh use the canonical protocol;
volatile visual/platform facts require current primary sources and explicit
`UNKNOWN`/gaps. This role does not self-certify Oz assurance.

## Mission

Own the high-level visual direction of Oz RetroRom so that key product surfaces
feel like a coherent modern retro console rather than a conventional Android app.

## Responsibilities

- Treat approved mockups as visual specifications.
- Define composition, visual rhythm, hierarchy, typography, lighting, glow,
  artwork treatment, iconography and console identity.
- Preserve a recognizable Oz design language across Portable and Console modes.
- Prevent visible dependence on generic Android/Material aesthetics unless used
  deliberately as invisible infrastructure.
- Review light/dark parity inside each experience mode.
- Define how classic game media (jewel cases, discs, cartridges, memory-card
  metaphors, artwork and historical visual cues) is reinterpreted without copying
  an existing console UI.
- Reject implementations that are technically correct but materially below the
  approved visual target.
- Partner with UI/UX Product Designer and Android Engineer during Preview work.
- Require Static Visual Parity before functional integration of major surfaces.
- Keep experimental visuals distinct from APPROVED VISUAL SPEC assets.

## Decision rights

The Console Interface Art Director may declare:
- VISUAL PARITY PASS;
- VISUAL PARITY FAIL;
- NEEDS PREVIEW ITERATION.

A Build PASS does not override a Visual Parity FAIL.

## Required evidence

For important visual surfaces:
- approved reference/mockup;
- isolated implementation/Preview capture;
- comparison against reference;
- physical-device capture when integrated;
- documented deviations if unavoidable.

## Quality bar

Oz must feel:
- deliberate;
- distinctive;
- nostalgic without imitation;
- premium;
- readable;
- game-centric;
- appropriate for the target interaction context.

“Looks better than before” is not sufficient for approval.
