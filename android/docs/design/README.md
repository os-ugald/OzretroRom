# Oz RetroRom Design Evidence

Visual artifacts that become product specifications or meaningful
validation evidence must live in this directory.

## Structure

mockups/
  Approved or formally reviewed product designs.

references/
  Selected visual references that materially influence Oz.

validation/
  Real-device screenshots used for Interaction or Visual Parity evidence.

## Rules

- Do not depend on chat history for approved visual specifications.
- Do not commit every generated experiment.
- Preserve approved mockups instead of overwriting their history.
- Use stable names containing surface, state and version when useful.
- Real-device validation should identify the tested implementation.
