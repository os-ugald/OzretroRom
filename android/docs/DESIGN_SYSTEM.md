# Arcade Marquee

Paleta: Deep Purple `#2B0D3D`, Arcade Purple `#6A31B7`, Lavender `#B78CFF`, Electric Blue `#00E5FF`, Near Black `#0D0B16`, Arcade Cream `#FFECC7`.

El azul eléctrico se reserva para foco, progreso y energía. El menú CRT mantiene fondo negro, glow azul y botones amplios sin scanlines agresivas.
